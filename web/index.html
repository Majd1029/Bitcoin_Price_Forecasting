How to read this

The R² near 0.997 is an artifact. Each XGBoost prediction is anchored on the previous actual close, so almost all the explained variance is yesterday's price, not skill. That is why a naive "tomorrow = today" baseline is shown next to it.

Log-returns, not prices. Trees can't predict above the highest price seen in training, so XGBoost models log-returns and rebuilds the price path from them.

Scored fairly. Tuning uses time-series cross-validation, scaling uses the training years only, and 7-day forecasts are scored every week of the test period using only data up to that day. Direction accuracy comes with a binomial test against a coin flip.

Volatility clusters. Calm weeks follow calm weeks, so how much the price will move is far more predictable than which way. The HAR model is a linear blend of the last day's, week's and month's volatility.
